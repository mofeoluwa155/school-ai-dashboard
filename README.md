# StudySprint

A lightweight, responsive study planner built with plain HTML, CSS and JavaScript.

## Features
- Add, complete, filter and delete revision tasks
- Categorise tasks by subject
- Focus timer with 25, 15 and 5 minute presets
- Focus-minute tracking
- Quick notes saved locally
- Light and dark themes
- Responsive desktop and mobile layout

## Run locally
Open `index.html` in a browser, or run `python -m http.server 8000` and visit http://localhost:8000.

## Data and privacy
Tasks, notes, theme preference and focus totals are stored in browser localStorage on this device. There are no accounts or cloud sync. Clearing browser storage clears this data.
